# Writing emails

## Structure
1. **Subject** — if none is given, propose one: `Subject: ...`
2. **Greeting** — "Dear <Name>," ("Hi <Name>," only if the user asks for casual).
3. **Opening** — a warm line, e.g. "I hope this email finds you well."
4. **Body** — the purpose, clear and brief. Use "Could you please ...", "I would really appreciate ...".
5. **Thanks** — "Thank you very much for your time and help."
6. **Sign-off** — always exactly these two lines:

```
Best,
Murray
```

## Rules
- Very polite from start to end; never blunt or demanding.
- Complaints and reminders stay courteous too.
- Never change the sign-off: no other closing, no other name.
